This workspace contains all of the software and information for the Livox Avia.

Setup after cloning repository:

`cd ws_livox/`

`source /opt/ros/lyrical/setup.bash `

`colcon build `

Normal use:

`source ./install/setup.sh`

`source /opt/ros/lyrical/setup.bash `

To launch packages, navigate to ~/ws_livox/src/livox_ros2_driver/livox_ros2_driver/launch and use `ros2 launch <filename>.py`

Repository modified from: https://github.com/Livox-SDK/livox_ros2_driver
